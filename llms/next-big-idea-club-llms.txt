# Next Big Idea Club

> Next Big Idea Club is a nonfiction book subscription club and podcast, curating the most important new nonfiction with a selection committee of Malcolm Gladwell, Adam Grant, Susan Cain, and Daniel Pink. Members receive curated new nonfiction, an app-based library, courses, and author interviews. The consumer experience is powered by a first-party WordPress REST API (members/v1) secured with OAuth 2.0 / OpenID Connect via the WP OAuth Server, integrated with Stripe for subscription billing and with native iOS/Android apps.

## APIs
- [Members API (members/v1)](https://nextbigideaclub.com/wp-json/members/v1): First-party subscription, membership, library, and course API.
- [WordPress REST discovery](https://nextbigideaclub.com/wp-json/): API index across 15 namespaces (members/v1, stripe, apple, android, automation, wp/v2, ...).
